# Upload mesh

Upload mesh vertex data to GPU (VRAM). Modifies the mesh in place.

## Usage

``` r
upload_mesh(mesh, dynamic)
```

## Arguments

- mesh:

  A mesh.

- dynamic:

  A logical. Whether the mesh data is dynamic.
