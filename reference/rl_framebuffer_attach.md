# Rl Framebuffer Attach

Rl Framebuffer Attach

## Usage

``` r
rl_framebuffer_attach(id, tex_id, attach_type, tex_type, mip_level)
```

## Arguments

- id:

  A non-negative integer.

- tex_id:

  A non-negative integer.

- attach_type:

  An integer.

- tex_type:

  An integer.

- mip_level:

  An integer.

## Examples

``` r
if (FALSE) {
rl_framebuffer_attach(0L, 0L, 0L, 0L, 0L)
}
```
