# Rl Copy Shader Buffer

Rl Copy Shader Buffer

## Usage

``` r
rl_copy_shader_buffer(dest_id, src_id, dest_offset, src_offset, count)
```

## Arguments

- dest_id:

  A non-negative integer.

- src_id:

  A non-negative integer.

- dest_offset:

  A non-negative integer.

- src_offset:

  A non-negative integer.

- count:

  A non-negative integer.

## Examples

``` r
if (FALSE) {
rl_copy_shader_buffer(0L, 0L, 0L, 0L, 10L)
}
```
