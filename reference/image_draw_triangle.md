# Image draw triangle

Draw triangle within an image. Modifies the image in place.

## Usage

``` r
image_draw_triangle(dst, v1, v2, v3, color)
```

## Arguments

- dst:

  An image.

- v1:

  A numeric vector of length 2.

- v2:

  A numeric vector of length 2.

- v3:

  A numeric vector of length 2.

- color:

  A color.
