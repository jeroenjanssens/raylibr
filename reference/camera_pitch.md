# Rotate camera around right axis (pitch)

Rotate camera around right axis (pitch)

## Usage

``` r
camera_pitch(camera, angle, lock_view, rotate_around_target, rotate_up)
```

## Arguments

- camera:

  A camera_3d.

- angle:

  A number. Rotation angle in radians.

- lock_view:

  A logical.

- rotate_around_target:

  A logical.

- rotate_up:

  A logical.
