# Rl Set Blend Factors Separate

Rl Set Blend Factors Separate

## Usage

``` r
rl_set_blend_factors_separate(
  gl_src_rgb,
  gl_dst_rgb,
  gl_src_alpha,
  gl_dst_alpha,
  gl_eq_rgb,
  gl_eq_alpha
)
```

## Arguments

- gl_src_rgb:

  An integer.

- gl_dst_rgb:

  An integer.

- gl_src_alpha:

  An integer.

- gl_dst_alpha:

  An integer.

- gl_eq_rgb:

  An integer.

- gl_eq_alpha:

  An integer.

## Examples

``` r
if (FALSE) {
rl_set_blend_factors_separate(0L, 0L, 0L, 0L, 0L, 0L)
}
```
