# Rl Draw Vertex Array Instanced

Rl Draw Vertex Array Instanced

## Usage

``` r
rl_draw_vertex_array_instanced(offset, count, instances)
```

## Arguments

- offset:

  An integer.

- count:

  An integer.

- instances:

  An integer.

## Examples

``` r
if (FALSE) {
rl_draw_vertex_array_instanced(0L, 10L, 0L)
}
```
