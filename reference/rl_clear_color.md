# Rl Clear Color

Rl Clear Color

## Usage

``` r
rl_clear_color(r, g, b, a)
```

## Arguments

- r:

  A non-negative integer (0-255).

- g:

  A non-negative integer (0-255).

- b:

  A non-negative integer (0-255).

- a:

  A non-negative integer (0-255).

## Examples

``` r
if (FALSE) {
rl_clear_color(255L, 255L, 255L, 255L)
}
```
