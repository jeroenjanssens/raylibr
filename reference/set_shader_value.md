# Set shader value

Set shader uniform value.

## Usage

``` r
set_shader_value(shader, loc_index, value)
```

## Arguments

- shader:

  A shader.

- loc_index:

  An integer.

- value:

  A number or numerical vector of length 2, 3, or 4.
