# Rl Compute Shader Dispatch

Rl Compute Shader Dispatch

## Usage

``` r
rl_compute_shader_dispatch(group_x, group_y, group_z)
```

## Arguments

- group_x:

  A non-negative integer.

- group_y:

  A non-negative integer.

- group_z:

  A non-negative integer.

## Examples

``` r
if (FALSE) {
rl_compute_shader_dispatch(0L, 0L, 0L)
}
```
