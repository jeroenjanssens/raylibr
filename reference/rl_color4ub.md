# Rl Color4ub

Rl Color4ub

## Usage

``` r
rl_color4ub(r, g, b, a)
```

## Arguments

- r:

  A non-negative integer (0-255).

- g:

  A non-negative integer (0-255).

- b:

  A non-negative integer (0-255).

- a:

  A non-negative integer (0-255).

## Examples

``` r
if (FALSE) {
rl_color4ub(255L, 255L, 255L, 255L)
}
```
