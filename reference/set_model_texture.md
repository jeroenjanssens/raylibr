# Set model texture

Set texture for a material map of a model. Modifies the model in place.

## Usage

``` r
set_model_texture(model, material_id, map_type, texture)
```

## Arguments

- model:

  A model.

- material_id:

  An integer. Material index.

- map_type:

  An integer. Material map type.

- texture:

  A texture.
