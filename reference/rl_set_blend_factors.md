# Rl Set Blend Factors

Rl Set Blend Factors

## Usage

``` r
rl_set_blend_factors(gl_src_factor, gl_dst_factor, gl_equation)
```

## Arguments

- gl_src_factor:

  An integer.

- gl_dst_factor:

  An integer.

- gl_equation:

  An integer.

## Examples

``` r
if (FALSE) {
rl_set_blend_factors(0L, 0L, 0L)
}
```
