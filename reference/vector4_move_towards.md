# Vector4 Move Towards

Vector4 Move Towards

## Usage

``` r
vector4_move_towards(v, target, max_distance)
```

## Arguments

- v:

  A numeric vector of length 4.

- target:

  A numeric vector of length 4.

- max_distance:

  A number.

## Value

A numeric vector of length 4
