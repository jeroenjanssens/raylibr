# Rl Blit Framebuffer

Rl Blit Framebuffer

## Usage

``` r
rl_blit_framebuffer(
  src_x,
  src_y,
  src_width,
  src_height,
  dst_x,
  dst_y,
  dst_width,
  dst_height,
  buffer_mask
)
```

## Arguments

- src_x:

  An integer.

- src_y:

  An integer.

- src_width:

  An integer.

- src_height:

  An integer.

- dst_x:

  An integer.

- dst_y:

  An integer.

- dst_width:

  An integer.

- dst_height:

  An integer.

- buffer_mask:

  An integer.

## Examples

``` r
if (FALSE) {
rl_blit_framebuffer(0L, 0L, 800L, 450L, 0L, 0L, 800L, 450L, 0L)
}
```
