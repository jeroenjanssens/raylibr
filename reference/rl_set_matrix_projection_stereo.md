# Rl Set Matrix Projection Stereo

Rl Set Matrix Projection Stereo

## Usage

``` r
rl_set_matrix_projection_stereo(right, left)
```

## Arguments

- right:

  A 4x4 numeric matrix.

- left:

  A 4x4 numeric matrix.

## Examples

``` r
if (FALSE) {
rl_set_matrix_projection_stereo(diag(4), diag(4))
}
```
