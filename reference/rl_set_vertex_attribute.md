# Rl Set Vertex Attribute

Rl Set Vertex Attribute

## Usage

``` r
rl_set_vertex_attribute(index, comp_size, type, normalized, stride, offset)
```

## Arguments

- index:

  A non-negative integer.

- comp_size:

  An integer.

- type:

  An integer.

- normalized:

  A logical.

- stride:

  An integer.

- offset:

  An integer.

## Examples

``` r
if (FALSE) {
rl_set_vertex_attribute(0L, 32L, 0L, TRUE, 0L, 0L)
}
```
