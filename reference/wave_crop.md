# Wave crop

Crop a wave to defined frames range. Modifies the wave in place.

## Usage

``` r
wave_crop(wave, init_frame, final_frame)
```

## Arguments

- wave:

  A wave.

- init_frame:

  An integer. Initial frame.

- final_frame:

  An integer. Final frame.
