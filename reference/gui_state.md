# Gui State

Enum values for `gui_state`.

## Usage

``` r
gui_state
```

## Format

An object of class `list` of length 4.

## Details

|            |       |
|------------|-------|
| Name       | Value |
| `normal`   | 0     |
| `focused`  | 1     |
| `pressed`  | 2     |
| `disabled` | 3     |
