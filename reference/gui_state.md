# Gui State

Enum values for `gui_state`.

## Usage

``` r
gui_state
```

## Format

An object of class `list` of length 4.

## Details

|            |       |
|------------|-------|
| Name       | Value |
| `normal`   | 0     |
| `focused`  | 1     |
| `pressed`  | 2     |
| `disabled` | 3     |

## Examples

``` r
gui_state$normal
#> [1] 0
gui_state$focused
#> [1] 1
gui_state$disabled
#> [1] 3
```
