# Rl Bind Image Texture

Rl Bind Image Texture

## Usage

``` r
rl_bind_image_texture(id, index, format, readonly)
```

## Arguments

- id:

  A non-negative integer.

- index:

  A non-negative integer.

- format:

  An integer.

- readonly:

  A logical.

## Examples

``` r
if (FALSE) {
rl_bind_image_texture(0L, 0L, 0L, TRUE)
}
```
