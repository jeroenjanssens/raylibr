# Image draw line ex

Draw line within an image (Vector version). Modifies the image in place.

## Usage

``` r
image_draw_line_ex(dst, start, end, thick, color)
```

## Arguments

- dst:

  An image.

- start:

  A numeric vector of length 2.

- end:

  A numeric vector of length 2.

- thick:

  An integer. Line thickness.

- color:

  A color.
