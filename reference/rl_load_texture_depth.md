# Rl Load Texture Depth

Rl Load Texture Depth

## Usage

``` r
rl_load_texture_depth(width, height, use_render_buffer)
```

## Arguments

- width:

  An integer.

- height:

  An integer.

- use_render_buffer:

  A logical.

## Value

An integer

## Examples

``` r
if (FALSE) {
rl_load_texture_depth(800L, 450L, TRUE)
}
```
